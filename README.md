# Devis Maquette — D-RIV3D Création

Logiciel de devis pour maquettes architecturales 3D. Il s'ouvre dans le navigateur et s'installe comme une appli (téléphone et PC).

Adresse : https://driv3dfr-wq.github.io/maquette-devis/

## Installer l'appli
- **Android** : ouvrir l'adresse dans Chrome → menu ⋮ → « Installer l'application ».
- **iPhone** : ouvrir dans Safari → Partager → « Sur l'écran d'accueil ».
- **PC** : ouvrir dans Chrome ou Edge → icône « Installer » dans la barre d'adresse.

## Données
Ce dépôt ne contient que l'appli, **aucune donnée client**. Les projets restent sur chaque appareil et, si la synchronisation est activée, dans le dossier « Devis Maquette » du Google Drive (voir `atelier-devis-drive.gs`).
